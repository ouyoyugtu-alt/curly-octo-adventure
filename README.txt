GALEIC FUTURES PRO V3

التغيير الأساسي:
- جميع عناصر الواجهة (مصدر البيانات، خانة البحث، الفريم، زر التحليل) تظهر قبل أي اتصال بالإنترنت.
- لذلك لن تختفي الأزرار إذا رفض مزود البيانات الاتصال.
- لا يتم تحميل قائمة العملات عند فتح الصفحة؛ اكتب رمز الزوج مباشرة مثل BTC أو BTCUSDT.
- المصدر الافتراضي OKX Futures، مع خيار Bybit Futures.
- لا يحتاج API Key ولا ينفذ صفقات.
- يتم استبعاد الشمعة غير المكتملة.

التحديث:
1. استبدل app.py و requirements.txt في GitHub بالملفين هنا.
2. Commit Changes.
3. انتظر Streamlit حتى يعيد تشغيل التطبيق.
4. افتح الصفحة واعمل Refresh.
5. اكتب BTC، اختر 15m، ثم اضغط تحليل العملة.
6. إذا فشل OKX، اختر Bybit وجرب مجدداً.

التشغيل المحلي:
pip install -r requirements.txt
streamlit run app.py

تنبيه: HTTP 403/451 قد ينتج عن سياسة وصول مزود البيانات أو شبكة الاستضافة. هذه النسخة لا تحاول تجاوز الحجب؛ تعرض عناصر الواجهة أولاً وتتيح اختيار مزود آخر.
